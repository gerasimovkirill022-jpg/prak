# Практические работы «Клиент-серверное приложение»

Учебный проект «Список задач» на Python + SQLite + Flask.

| Папка | Работа |
|---|---|
| `прак1` | Инициализация базы данных SQLite |
| `прак2` | Базовые CRUD-операции через консоль |
| `прак3` | Подключение Flask и первый маршрут |
| `прак4` | Интеграция Flask и SQLite (чтение данных) |
| `прак5` | Интеграция Flask и SQLite (добавление данных) |
| `прак6` | Обработка ошибок и защита соединений |
| `прак7` | Мини-проект «Список задач» (итоговая работа) |

В каждой папке: PDF-отчёт с ответами на вопросы, `скриншоты/` и `src/` с кодом этой работы.
`task_manager/` — итоговая версия проекта.

## Запуск

```
pip install flask
cd task_manager
python init_db.py
python app.py
```

Открыть в браузере: http://127.0.0.1:5000
